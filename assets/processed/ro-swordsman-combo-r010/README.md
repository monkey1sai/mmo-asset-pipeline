## 可觀察的改善及限制

在原五個完整指腹遮罩中，每指距柄<=2mm的點數由3/1/3/0/3改善至3/3/3/3/3。
75個無名指/食指形體點使用可關閉局部修形，原Basis、UV、骨位、權重及203拇指點無額外修改。
受測121個時間點（整幀＋半幀）的自交、手劍橫向交叉與未解分類門檻通過。
這是有限樣本與保守形變檢查；不等於連續時間無交叉證明，也不等於美術包握已接受。
獨立灰模審查見側面仍偏鬆、指節偏硬，故不能宣稱整个握持功能關卡PASS。

官方GLB匯出器會略去微小權重。repo內後處理按原ID恢復全部FLOAT32權重，所有其他bytes一致。
fresh回讀手最大0.193858µm、RMS0.041020µm，容差仍為1µm；劍實際跟隨最大0.153598µm。
原兩clip、權重缺失GLB與失敗回讀均保留。完整紀錄位於`runs/qa/ro-swordsman-combo-r010/`。

尚待處理：16跨UV島面／材質、握姿美術、左手、手腕與衣甲配裝、300幀連續技能與獨立VFX。
