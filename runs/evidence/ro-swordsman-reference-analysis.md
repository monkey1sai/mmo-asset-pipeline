# RO 劍士連續技能：製作前參考分析

來源由使用者指定：`C:\.llmcode\ro_swordsman_animation`。僅唯讀取用；原始照片、十二張透明姿勢圖與 5 秒影片保存於本需求的來源版本，不修改來源資料夾。提供參考不代表原作商業授權，交付說明保留這一限制。

## 造型契約

同一名年輕男性動漫劍士：棕色尖髮、銀灰分片胸甲與肩甲、深藍短外套／分叉裙擺、白色前襟、棕色手套／腰帶／皮靴。直刃雙刃銀劍、小型黃銅護手、棕色握柄。照片間臉部／甲片細節略有變動；以透明姿勢 01、12 的一致元素為主。場景、標題字、觀眾與火光不屬於角色幾何。

不以動作照片冒充同姿勢多視角。背面、甲片厚度及不可見部位需設計推定並記錄；不宣稱照相測量還原。白襟與藍色分叉衣擺保留獨立活動結構，劍為獨立掛點。

## 動作契約

來源影片容器實測 1376×768、60 fps、300 frames、5 秒；這只驗證參考影片格式。目標為真正 humanoid 骨架與逐格可變的三維姿勢，非圖片輪播或攝影機移動。

十二張參考順序涵蓋：預備／挑釁、上舉蓄力、前進、跳起、落地、狂擊斬落、轉身蓄力、下刺／轉斬、水平旋斬、怒爆、霸體、勝利收勢。2D 參考不能確定每個中間關節，插值與接續由動畫製作補足。火焰與光圈為分離的展示效果，不能取代骨骼動作，也不修改遊戲傷害或碰撞。

## 生產決策

採本機 Blender 4.5.5 程序建模作真實 baseline，可編輯 master＋GLB、骨架、權重、5 秒／60 fps 連續動畫。獨立資產，未指定遊戲引擎。實際視覺比對後才決定是否可交付；不能以幾何存在或測試全綠宣稱頂尖品質。

預先固定五視角、材質與中性棚光、姿勢表、近景與額外未參與評分的角度。最多三個候選；未達標保留候選與失敗證據，不 push main。骨架／姿勢／匯出 roundtrip、實際畫面、品質迴圈判定是不同門檻。
