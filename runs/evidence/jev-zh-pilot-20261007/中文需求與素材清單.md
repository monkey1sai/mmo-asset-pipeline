## 比較結果與限制

僅比較成功的相同 7 案：Jev 分類符合預期 7/7，既有 intake 的靜態預設為 2/7；這是功能缺口對照，不是與另一個語意分類器競賽。素材 Choice 為 7/7；同候選集合的 Jev 與中文字面排序 baseline 均為 Top-1 7/7、MRR 1.0，因此目前沒有排序品質提升的證據。

成功回覆共 20,488 input tokens、1,449 output tokens；依凍結官方費率估算為 USD 0.0008605。第 8 筆失敗請求沒有 usage 回覆，其用量與實際帳戶扣款未核實。成功請求平均 243.19 ms，僅量測 provider 呼叫至回覆契約核對，不包含美術製作。

33 個候選摘要包含 28 個沒有實體模型的合成條目及 5 個既有素材版本 metadata。本次未驗模型、美術、骨架、動畫或引擎，也未修改素材庫、套用 Jev 選擇或呼叫 Hyper3D。

完整機器結果見 `report.json`，操作紀錄見 `operations/`，凍結依據見 `manifest.json`，獨立來源審查見 `preflight/independent-risk-review.md`。HTTP 503 後停止是本次 manifest 的已凍結停止條件；維持原 run、預期標籤與失敗紀錄，不藉新 ID 清除失敗。
