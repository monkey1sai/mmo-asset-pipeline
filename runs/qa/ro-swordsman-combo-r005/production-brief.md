# RO 同圖六件批量來源實驗

## 目前狀態

輸入設計與一笔 API 計畫已準備，尚未提交。使用者同意先做一筆批量生成，再以實際缺陷決定個別補件。原六筆獨立計畫及所有舊候選保持原狀；commit、push 等使用者驗證。

## 可驗證假設

一張輪廓互不重疊的產品圖可能用一筆生成取得多個有用部件，減少初次生成數量。這是假設，API 未保證六個完整獨立模型；連通幾何數也不等於有用部件數。初次估算0.5點，實際以服務 consumed 回報；後續補件按需求及證據處理，無加購／升級。

## 輸入與修訂紀錄

以原六張設計為源；image_gen 最多5張參考，採角色、胸甲、肩甲、護臂、衣襬參考，文字定義長劍。第一張同圖的左緣安全距離不足且有暈光；第二張修正完整邊界但暈光仍在；第三張改用白底，六件完整輪廓可辨識且無明顯彩色暈光。三張全部保存至 design-v004；不宣稱任何一張是3D渲染或美術品質提升。腳本僅複製原始圖片及讀取尺寸／hash，未編修圖片。

| 部件 | 生成後必要檢查 | 可接受後製 | 應補生成的證據 |
| --- | --- | --- | --- |
| 角色核心 | 正側背立體厚度、頭身比例、兩手掌與五指、肩肘髖膝構造 | 尺寸軸向、局部收邊、可控拓樸／權重修正 | 缺肢、扁平紙片、多指融合、需要大幅重建 |
| 胸甲 | 獨立空殼、頸／臂／腰開口、前背厚度 | 內側、接合、剛性掛點與尺寸 | 與角色融合、缺背面或完全實心且修復成本過大 |
| 肩甲 | 獨立肩帽及疊片、有可信內側 | 尺寸、鏡像、片間讓位、剛性骨 | 漏件、融合、不可辨识或破面 |
| 護臂 | 完整筒殼、兩端開口、繫帶 | 軸向、內側、鏡像、剛性骨 | 漏件、融合、手臂被一起生成且無法合理拆除 |
| 衣襬 | 腰帶、兩側襬與前襟、可分離面片 | 衣片骨、接合、適度厚度和動作讓位 | 漏襬、閉裙、大片黏合或平面貼圖替代形體 |
| 劍 | 完整刃／格／柄／首，側面厚度 | 柄pivot、比例、掛點、邊緣細節 | 漏件、只有平面剪影、與其他物體融合 |

尺度在設計板刻意放大以看清小部件；生成位置／比例不能直接當角色組裝契約。Blender 依1.74m角色與實際人體重新配裝，完成角色與劍仍不得超過60,000三角面。

## API 計畫

operation: ro-split-batch-20261003-001。Gen2.5 High、Quad、總面數規劃22,000、PBR/high貼圖、seed4500、TAPose=false、symmetry=unknown。不啟用額外高價選項；多件圖不使用單一人體TAPose條件，避免干擾零件配置。參數不保證實際面數或拓樸。

公開需求／圖／參數hash在 runs/hyper3d/plans。需另獲使用者指定的 repo 外新任務檔寫入授權；點數使用已有授權。不修改密鑰、舊授權、舊任務或全域設定。pending/unknown不重送，先對帳；已完成才下載。

## Blender 檢查與後續

inspect_ro_batch_source.py 僅接受這筆已下載且hash匹配的GLB，在新目錄建立可編輯master、source GLB、材質依賴、五個來源視角、連通幾何與面數紀錄。診斷合併相同座標只用於鄰接計算，原UV和網格不合併。它不自動宣稱六個語義部件、手部、骨架或動畫PASS。

實際閱圖並將每個部件標為可用、局部修訂、補生成或未驗；只有有缺陷證據的部件才補生成。缺件／融合不得靠多張美化圖或其餘部件分數抵銷。補生成需新operation與輸入／成本紀錄；未知操作先處理。組裝中性baseline後，先驗開掌、握持、過頭、下劈、蹲與落地，再製作完整300幀60fps連段及可關閉效果，乾淨GLB重匯入全段回讀。
