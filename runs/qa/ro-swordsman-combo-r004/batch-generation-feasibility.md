# 單張多部件輸入與成本查證

2026-10-03，使用者詢問：Hyper3d應該允許一張圖放多個模型來產生吧？這樣可以只算一次扣點嗎。

這是方案／成本問題，不是對先前六個新任務恢復檔的授權。六筆原計畫保留 prepared，未付費提交；本查證沒有新外部寫入、全域檔案或 Git 操作。

## 官方可確認

- Rodin Gen-2.5 收取基礎每筆生成0.5點；Extreme-High增加0.5，extreme-high texture增加2.0。實際consumed仍以服務回覆為準。以一張多物件圖提交單筆基礎任務，計費計畫可是一筆0.5；文件未承諾得到指定數量的獨立、完整、可活動部件。
- images接受1至5張參考，一次傳多張不等於產生對應數量的獨立資產。
- BANG可對已完成Rodin來源或上傳自訂模型拆件；instruction可指示拆分方式，strength影響拆分程度。BANG每筆另收0.5點，不能算在原Rodin生成內。
- 本機已驗證repo入口尚不支援BANG transport；可見MCP工具不代表與已驗證API帳戶相同或可直接使用。不得繞過provider allowlist或修改全域檔案。

## 製作推論，尚未實測

單張分件板可以設計成六件清楚分離、不重疊、光照與視角一致的輸入。是否全數保留、是否被融合、隱藏表面與相對尺度是否成立，要檢查實際生成GLB，不由圖像或任務成功推定。共用一個生成結果的幾何/貼圖資源也可能減少小件細節。

## 三種可比較方向

1. 單張分件板→一次Rodin→Blender實際拆件/檢查：初次估算0.5點。優先作低成本可行性實驗；融合/缺件則保存失敗證據，按問題選補件或拆件，不能宣稱總成本永遠0.5。
2. 一次Rodin→BANG→Blender：基礎估算共1.0點。BANG是另一筆任務與付費操作，仍要驗完整部件、接合與變形；先核對受支援入口，不宣稱本機已接通。
3. 六件分別Rodin→Blender組裝：初次估算共3.0點。每件輸入/品質可獨立控制，但付費工作及組裝更多；成功及更高品質仍非保證。

建議先驗方向1，再依具體缺陷選方向2或僅缺件的獨立生成。這是待選方案；本文件不修改已凍結需求/預算、舊操作或任何付費執行授權。
